# 🚀 My-Portfolio-Website

## 📝 Description

A modern, responsive personal portfolio website showcasing projects, skills, certifications, and professional journey. Built with React, TypeScript, and Tailwind CSS, this portfolio demonstrates my web development skills and provides an interactive showcase of my work.

## 🌟 Features

### Key Sections
- 🏠 Home/Landing Page
- 👤 About Me
- 💼 Experience
- 🎓 Education
- 🛠 Skills
- 📂 Projects
- 🏆 Certifications
- 📞 Contact

### Technical Highlights
- Fully Responsive Design
- Smooth Animations with Framer Motion
- Dark Theme
- Lazy Loading
- Intersection Observers
- Animated Skill Bars
- Project Carousel
- Optimized Performance

## 🛠 Technologies Used

### Frontend
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Shadcn UI Components

### Development Tools
- Vite
- ESLint
- Prettier

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or later)
- npm or yarn

### Installation Steps
1. Clone the repository
```bash
git clone https://github.com/RahulRmCoder/My-Portfolio-Website.git
```

2. Navigate to project directory
```bash
cd My-Portfolio-Website
```

3. Install dependencies
```bash
npm install
# or
yarn install
```

4. Run development server
```bash
npm run dev
# or
yarn dev
```
